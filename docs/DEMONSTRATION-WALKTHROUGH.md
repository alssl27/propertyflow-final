# Demonstration walkthrough

Prepared on 14 October 2026. These are practice instructions and expected outcomes, not a record of a learner demonstration. Allow about 10–15 minutes. Record your own observations separately using the [results template](TEST-RESULTS-TEMPLATE.md).

Open the [live app](https://propertyflow-final.vercel.app) in a fresh browser profile or private window. This gives a separate fictional workspace. Reload persistence can be demonstrated within the same private session; closing it may remove its storage. Existing saved workspaces can have different totals from the seed values below.

| Step                     | Action                                                                                                                                                                     | Expected observation and explanation                                                                                                                                                                                          |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Overview              | Review the fresh portfolio and attention shortcuts.                                                                                                                        | The seed register has 8 properties: 5 occupied, 2 vacant and 1 in maintenance. Occupancy rounds to 63%; occupied monthly rent is £5,350. Explain that totals come from records rather than hardcoded dashboard figures.       |
| 2. Search                | Open Properties, search `Abbeyhills`, then use Clear filters. Select Vacant, then clear again.                                                                             | Search identifies the Abbeyhills Road record; clear restores all 8. The fresh Vacant filter shows 2. Explain combined filters and the 180 ms local debounce.                                                                  |
| 3. Validation and add    | Open Add property and submit the empty form. Correct it with fictional address `27 Review Lane`, postcode `OL8 2AB`, 2 bedrooms, monthly rent `1250`, status Vacant; save. | Invalid fields have readable errors and focus moves to the first error. A valid save adds one record and increases total properties to 9.                                                                                     |
| 4. Duplicate and edit    | Try adding the same address/postcode again; cancel after the duplicate warning. Edit the existing Review Lane property to Occupied.                                        | The duplicate does not add a second record. The occupied count becomes 6; occupancy rounds to 67% and occupied rent becomes £6,600. Explain normalised duplicate identity and successful persistence before UI success.       |
| 5. Persistence           | Reload the page, then locate Review Lane again.                                                                                                                            | The saved property and occupied status remain in the same browser origin/profile. Explain the single `propertyflow.workspace.v2` snapshot and why this is not server storage.                                                 |
| 6. Repairs               | Open Repairs → Log repair. Choose Review Lane, description `Review leaking kitchen tap`, priority Urgent and status Open; save. Use Update status three times.             | The record progresses Open → Scheduled → In progress → Completed. The action then becomes Reopen. Explain property IDs, validation and the explicit lifecycle.                                                                |
| 7. Certificate dates     | Open Compliance → Add certificate. Choose Review Lane, type Gas Safety Certificate and today's expiry date; save. Edit its expiry to yesterday.                            | Today is Due soon; yesterday is Overdue. The register is sorted by expiry. Explain the inclusive 30-day boundary and that this educational classification does not establish legal compliance.                                |
| 8. Linked deletion       | Return to Properties and try deleting Review Lane, confirming the attempt.                                                                                                 | Deletion is blocked because the repair and certificate reference the property, including the completed repair. Explain why preventing orphan records is preferable to silently dropping related data.                         |
| 9. Reports               | Open Reports and use Export CSV. Inspect the downloaded file.                                                                                                              | Summaries reflect current records. The property CSV includes Review Lane and current status/rent. Explain CSV quote escaping and formula protection; it is a property export, not a full workspace backup or payments ledger. |
| 10. Keyboard and history | Open Add property, move through controls using Tab/Shift+Tab, use Escape, then try browser Back/Forward between views.                                                     | Focus stays in the modal while open; Escape closes it and returns focus. Hash routes support browser history. Explain native dialogs, focus management, described errors and the limits of automated accessibility checks.    |
| 11. Reset                | In this separate demo session, open Settings and Reset demo data, then confirm.                                                                                            | The fictional seed workspace is restored: 8 properties and no Review Lane record. Explain that replacement data is fetched and validated before the atomic save; failed resets preserve the old snapshot.                     |

For missing-path recovery, open [an unknown page](https://propertyflow-final.vercel.app/demonstration/missing-page) and use Return to Dashboard. The expected HTTP result is 404 with the custom page; missing JSON assets also remain errors. Existing production verification is in [deployed results](DEPLOYED-TEST-RESULTS.md).

## Explain the code and evidence

Open `assets/js/domain.js` for pure calculations/validation, `assets/js/api.js` for Fetch/Promise.all/AbortController and queued persistence, and `assets/js/app.js` for routing/events/rendering. Use tests A01/A13–A16 to explain overlapping writes, out-of-order fetch completion, rejection and virtual timeout cancellation. See the [handover](LEARNER-HANDOVER.md) for worked assessor questions.
