## What the excerpt does not settle

The supplied pages do not prescribe:

- a particular screen reader;
- a physical touch-device test;
- Firefox or Safari testing;
- an actual operating-system contrast-mode test;
- a fixed number or exact format of screenshots;
- upload file types or size limits for the learner's submission portal; or
- the centre-specific permission and declaration process for AI-assisted assessed work.

Those items must not be inferred. The manual and learner checks remain open where they have not genuinely occurred. The learner must inspect the actual portal and obtain the applicable centre/tutor decision before submission.

## Screenshot decision

The supplied criterion 3.3 asks for screenshots of the finished project aligned with the user stories. The existing [evidence checklist](evidence-checklist.md) already maps genuine captures to US01–US10, so the supplied excerpt itself creates no identified need for an additional screenshot. The learner should still add anything specifically requested by the assignment brief, tutor or portal, because those sources were not supplied here.
